# BALTSAR 案例：构造与验证入口

适用基线：2026-09-21 本地 `parapoly-engine@3.0.1` Native、配套 runtime/WASM；示例版本 2.2.0。同版本号不能代替构建身份，公开版未附内部验证环境，模型身份可读 [模型资料](../../../model-info.json)。此案例的尺寸和阈值只用于这把椅子。

## 设计约束与代码位置

最终款式为黑色四腿椅，580×570×850 mm，座高450、座宽460、座深440。早期白色转椅款的底座及旋转参数已移除，不应从旧示例图恢复。

全部几何在 [main.code3d.js](../../../main.code3d.js)，辅助检查不参与模型运行：

| 源码入口 | 用途与复用判断 |
| --- | --- |
| `baltsarSurface` | 同一 YZ 基准曲线结合横向变化，服务透明壳及外侧承托碗 |
| `baltsarFrame` | 纵向法线与横向斜率补偿，避免仅在截面里看起来足够厚 |
| `baltsarRibbon` | 两侧厚度表面及圆头组成闭合平面截面 |
| `baltsarShellRows` | 分别生成承托碗和透明壳；透明壳侧缘有椭圆收拢和加密站位 |

主体名义厚度9 mm。设纵向截面的单位法线为 `n`，基准面横向导数为 `dP/dx`，本例截面厚度乘以 `sqrt(1 + dot(dP/dx,n)^2)` 作局部补偿。有限差分和放样插值会引入误差，不能把这个式子当成全曲面严格等厚证明。

承托碗使用相同基准面，名义厚度12 mm，向外偏置并留3 mm展示间隙。实际连接与间隙均为照片推定，不是制造装配或强度结论。

## 三次用户反馈对应的修正

**薄壁、断边与穿帮。** 早期壳在侧端收敛，两个独立边管断开，承托碗与壳分别拟合。旧版探针最小约0.64 mm，壳碗交集约133359.52 mm³。改为连续厚壳、共用曲面偏置，并调整座垫与腿顶，使用真实交集复验。透明度不能修复几何。

**顶部过尖。** 原横向高度衰减过快。上部改为较平缓的六次幂分布，在纵向参数0.76以上平滑引入，并在横向外缘恢复原边界，保留端部截面。800/830 mm高度的截线宽度从约242/154 mm增至443/378 mm。检查门槛420/300 mm是照片轮廓约束，不是厂家数据。

**侧缘被平面切断。** `spline_loft` 自动把两端封成平面，原每侧面积约2215 mm²。仅“实体闭合”不足以检验外观。最终在 `|x| > 270` 的20 mm范围内，将截面围绕基准曲线中点收拢，权重为：

```js
const r = Math.sqrt(1 - .9975 * ((Math.abs(x) - 270) / 20) ** 2);
```

该权重与端部加密站位共同作用；不能只复制公式到另一组截面。粗站位出现过尖褶，极小截面的硬下限方案出现过6条非流形焊接边，最终平滑方案在原精度下归零。端部保留有限小封口，最终每侧约5.5..5.6 mm²，非拓扑意义的“零平面”。主体20个探针最小约8.89 mm，圆弧自由边会收拢。

## 复用诊断经验

这是公开展示版案例。内部几何回归脚本、浏览器 Worker 环境和历史失败模型不随本仓库分发，不能在此直接运行原内部验证命令。需要验证新的模型时，使用安装的引擎能力重新建立检查：

- 对真实网格按高度截线，核对顶部宽度，而非只核对整体包围盒。
- 检查两侧外缘所有横向平面的面积，不能只看最外极值平面，否则可能漏掉放样超调内侧的封口。
- 沿表面法线量取厚度，用实体交集检查壳、内件及支腿，确认相交输入有效，避免空检查。
- 分别在可用的 Native 与 Web/WASM 环境执行同一模型并导出；缺少某个后端时如实记录未验证范围。

在仓库根目录安装支持所需 API 的 `parapoly-engine` 后，可按[本例说明](../../../README.zh-CN.md)导出 GLB/STEP。普通导出不等于上述结构检查已经通过。历史验证摘要与下载哈希见 [模型资料](../../../model-info.json)。
