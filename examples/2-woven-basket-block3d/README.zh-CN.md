# 竹编容器

[English](README.md) · [全部示例](../../README.zh-CN.md)

重复排列的曲面条带构成镂空编织容器。

<picture><source media="(prefers-color-scheme: dark)" srcset="preview.png"><img src="preview-light.png" alt="竹编容器" width="640"></picture>

使用 [parapoly-engine](https://www.npmjs.com/package/parapoly-engine) 设计。

## 下载与源码

| File / 文件 | Size / 大小 |
| --- | --- |
| [GLB](dist/models/main.glb) | 1.63 MiB |
| [STEP](dist/models/main.step) | 3.95 MiB |

[main.code3d.js](main.code3d.js) · [模型资料](model-info.json)

GLB 用于三维查看，STEP 用于 CAD。点击文件后用 GitHub 的 Download raw file 获取；完整克隆请使用 Git LFS。

在仓库根目录安装 npm 包后，可运行：

```sh
npx --no-install parapoly-engine export examples/2-woven-basket-block3d/main.code3d.js -f glb,step -o generated/2-woven-basket-block3d
```
