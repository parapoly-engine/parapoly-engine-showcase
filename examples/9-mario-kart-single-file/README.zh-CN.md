# 无人物卡丁车

[English](README.md) · [全部示例](../../README.zh-CN.md)

开放座舱、曲面车罩、圆肩轮胎与中空排气管组成的卡丁车。

GLB 用于三维查看，STEP 用于 CAD。点击文件后用 GitHub 的 Download raw file 获取；完整克隆请使用 Git LFS。

在仓库根目录安装 npm 包后，可运行：

```sh
npx --no-install parapoly-engine export examples/9-mario-kart-single-file/main.code3d.js -f glb,step -o generated/9-mario-kart-single-file
```
