# 阶梯法兰盘

[English](README.md) · [全部示例](../../README.zh-CN.md)

带中心通孔和六个均布螺栓孔的阶梯法兰盘。

<picture><source media="(prefers-color-scheme: dark)" srcset="preview.png"><img src="preview-light.png" alt="阶梯法兰盘" width="640"></picture>

使用 [parapoly-engine](https://www.npmjs.com/package/parapoly-engine) 设计。

## 下载与源码

| File / 文件 | Size / 大小 |
| --- | --- |
| [GLB](dist/models/main.glb) | 0.13 MiB |
| [STEP](dist/models/main.step) | 0.08 MiB |

[main.code3d.js](main.code3d.js) · [模型资料](model-info.json)

GLB 用于三维查看，STEP 用于 CAD。点击文件后用 GitHub 的 Download raw file 获取；完整克隆请使用 Git LFS。

在仓库根目录安装 npm 包后，可运行：

```sh
npx --no-install parapoly-engine export examples/13-stepped-flange/main.code3d.js -f glb,step -o generated/13-stepped-flange
```
